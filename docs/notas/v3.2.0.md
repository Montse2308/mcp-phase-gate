# mcp-phase-gate 3.2.0

*Published on npm on 2026-10-19. In Spanish: [Español](#español).*

Two things arrive together: the **Studio**, a local web app that shows what the server sees, and **English next to Spanish** everywhere: prompts, presets, server messages and the Studio.

**This version includes everything that was going to be 3.1.0, which was never published.** The `v3.1.0` tag was pushed on 2026-10-18 on the merge of pull request [#54](https://github.com/Montse2308/mcp-phase-gate/pull/54) (commit `553bb64`), where `package.json` still said 3.0.0. The publish workflow failed at its step «Comprobar que el tag coincide con package.json», nothing reached npm, and that tag no longer exists. The Studio, which is what 3.1.0 was about, shipped here.

## What's in it

- **The Studio**, `npx mcp-phase-gate ui`: a local server on `127.0.0.1` with a one-time token, `Host` and `Origin` checks and a strict CSP, a read API over the same functions the tools use, and live events (SSE). Its views: Network, Board, Workshop, Lookout and Logbook. It only writes configuration, always in two steps (a preview, then Apply, which checks the disk hasn't changed). The server leaves a record of its open MCP sessions, which the Studio shows.
- **A demo and a static site.** `ui --demo` runs the Studio on example projects (multi-repo, an AI agent and research) with real, deterministic git commits, in a temporary folder. `ui --export-static` writes it as a read-only site, and the workflow publishes it on GitHub Pages.
- **English and Spanish.** A project's language is deduced from its documents on disk, and a task can be written in the other language (`redaccion`). The server's messages, `doctor`, `--help`, `init`, `eject` and the descriptions of the tools exist in both. The English prompts, commands, rules and presets are rewritten against a fixed glossary, not machine-translated. The Studio has its own language selector.
- **The README is in English** (the Spanish one is its twin), with a case study. A GIF and a video of the demo are generated on every publication.
- **Fixes.** A manifest without `idioma` stays Spanish, and `init --migrate` completes it. `IDIOMA-CON-TAREAS` also stops `start_task`, `record_batch` and `get_batch_status`. `doctor` warns about a `PHASE_GATE_LANG` that isn't `es` or `en`. The Pages workflow separates its permissions and pins its actions by SHA.

Pull requests: [#54](https://github.com/Montse2308/mcp-phase-gate/pull/54) and [#55](https://github.com/Montse2308/mcp-phase-gate/pull/55).

## What changes if you upgrade from 3.0

Your existing Spanish projects stay Spanish: without `idioma` in the manifest, the language is deduced from their documents before anything else.

### Qué trae

- **El Studio**, `npx mcp-phase-gate ui`: un servidor local en `127.0.0.1` con un token de un solo uso, comprobación de `Host` y `Origin` y una CSP estricta, una API de lectura sobre las mismas funciones que usan las tools, y eventos en vivo (SSE). Sus vistas: Red, Tablero, Taller, Vigía y Bitácora. Solo escribe configuración, siempre en dos pasos (una vista previa, y Aplicar, que comprueba que el disco no cambió). El servidor deja constancia de sus sesiones MCP abiertas, que el Studio enseña.
- **Una demo y un sitio estático.** `ui --demo` ejecuta el Studio sobre proyectos de ejemplo (multi-repo, un agente de IA y una investigación) con commits de git de verdad y deterministas, en una carpeta temporal. `ui --export-static` lo escribe como un sitio de solo lectura, y el workflow lo publica en GitHub Pages.
- **Español e inglés.** El idioma de un proyecto se deduce de sus documentos en disco, y una tarea puede escribirse en el otro idioma (`redaccion`). Los mensajes del servidor, `doctor`, `--help`, `init`, `eject` y las descripciones de las tools existen en los dos. Los prompts, comandos, reglas y presets en inglés se reescribieron con un glosario fijo, no se tradujeron a máquina. El Studio tiene su propio selector de idioma.
- **El README es en inglés** (el de español es su gemelo), con un caso de estudio. Con cada publicación se generan un GIF y un video de la demo.
- **Arreglos.** Un manifiesto sin `idioma` sigue en español, e `init --migrate` lo completa. `IDIOMA-CON-TAREAS` frena también a `start_task`, `record_batch` y `get_batch_status`. `doctor` avisa de un `PHASE_GATE_LANG` que no es `es` ni `en`. El workflow de Pages separa sus permisos y fija sus actions por SHA.
