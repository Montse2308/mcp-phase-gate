# mcp-phase-gate 2.0.1

*Published on npm on 2026-10-14. In Spanish: [Español](#español).*

The first version published by the workflow, with npm provenance, and the first with a tag. The one before it, **2.0.0**, was published by hand on 2026-08-10 from a machine with two-factor authentication: npm doesn't let you set up a trusted publisher for a package that doesn't exist yet, so the first version had to go out another way. For that reason 2.0.0 has **no tag** (it would only have made the workflow try to publish it again) and no provenance badge, which only CI can generate. The tags of this repository start at `v2.0.1`.

## What's in it

Everything since 2.0.0:

- **Hardening.** Tasks, projects and files can no longer leave their folder, and the segments of `file_path` are validated. `read_cross_repo` is limited to the repository you ask for and its reads are bounded. Every tool validates its arguments before using them.
- **Phase 2 translates the change for whoever asked for the ticket**, in plain language ([#41](https://github.com/Montse2308/mcp-phase-gate/pull/41)).
- **Dependencies.** The MCP SDK is updated and `ts-node` is gone. Dependabot watches the repository, grouping minor and patch updates and ignoring major versions of TypeScript and `@types/node`.
- **CI also runs on Windows**, and the tests cover the required paths, the tasks subfolder and the state.
- **Repository.** The READMEs are aligned with phase 5 and the package name, and the version 3 plan is versioned.

## Español

*Publicada en npm el 2026-10-14.*

La primera versión publicada por el workflow, con procedencia de npm, y la primera con tag. La anterior, la **2.0.0**, se publicó a mano el 2026-08-10 desde una máquina con autenticación en dos pasos: npm no deja configurar un editor de confianza para un paquete que todavía no existe, así que la primera versión tenía que salir por otro camino. Por eso la 2.0.0 **no tiene tag** (solo habría hecho que el workflow intentara publicarla otra vez) ni insignia de procedencia, que solo la puede generar CI. Los tags de este repositorio empiezan en `v2.0.1`.

### Qué trae

Todo lo que pasó desde la 2.0.0:

- **Endurecimiento.** Las tareas, los proyectos y los archivos ya no pueden salirse de su carpeta, y se validan los segmentos de `file_path`. `read_cross_repo` se limita al repositorio que pides y sus lecturas tienen tope. Cada tool valida sus argumentos antes de usarlos.
- **La Fase 2 traduce el cambio para quien pidió el ticket**, en lenguaje llano ([#41](https://github.com/Montse2308/mcp-phase-gate/pull/41)).
- **Dependencias.** Se actualiza el SDK de MCP y se va `ts-node`. Dependabot vigila el repositorio: agrupa las actualizaciones menores y de parche, e ignora las versiones mayores de TypeScript y de `@types/node`.
- **El CI también corre en Windows**, y los tests cubren las rutas obligatorias, la subcarpeta de tareas y el estado.
- **Repositorio.** Los README quedan alineados con la Fase 5 y con el nombre del paquete, y el plan de la versión 3 queda versionado.
